## DOSBox Staging accessibility fork

The emulator is a derivative of DOSBox Staging and remains GPL-2.0-or-later.
Its upstream `LICENSE`, source headers, copyright history, and bundled
third-party license files are retained. The accessibility modifications are
published under those applicable terms; the umbrella MIT license does not
relicense the emulator.

## DarkText

DarkText's source and tests are MIT licensed. Its Python dependencies are not
vendored and retain their own permissive licenses: RapidOCR (Apache-2.0),
ONNX Runtime (MIT), OpenCV Python packages (Apache-2.0), and NumPy's declared
permissive license set. Piper executables and voice models are installed
separately and are not redistributed.

## Darklands Coords

Darklands Coords and its add-money utility use only the Python standard library
and are MIT licensed. File offsets and structures document interoperability
facts about user-owned save data; no third-party reference implementation is
included.
